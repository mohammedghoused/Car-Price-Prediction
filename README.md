# 🚗 Car Price Prediction using Machine Learning

This project predicts the price of a used car using Machine Learning.  
The model is trained on the Quikr Car Dataset and deployed using Flask.

## Features
- Predict car price based on:
  - Company
  - Model
  - Year
  - Fuel type
  - Kilometers driven
- Simple web interface
- Machine learning model using Scikit-learn
- 
## Tech Stack
- Python
- Pandas
- Scikit-learn
- Flask
- HTML/CSS
- 
## Dataset
Quikr Used Cars Dataset

## How to Run
1. Clone the repository
2. git clone https://github.com/mohammedghoused/car-price-prediction.git
3. Install dependencies
pip install -r requirements.txt
4. Run the Flask app
python app.py
5. Open browser
http://127.0.0.1:5000
